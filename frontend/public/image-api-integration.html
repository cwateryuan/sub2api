97API 生图接口对接文档

本文档说明文生图与图生图接口的请求地址、鉴权方式、参数格式、返回结构和尺寸约束。

廉价渠道不支持2K 4K，传参也只能生成1K.请一定阅读尺寸规则
鉴权 文生图 图生图 返回格式 尺寸规则

鉴权与通用 Header

请求需要携带 Bearer Token。请将示例中的 YOUR_API_KEY 替换为实际密钥。

Header Value 说明
Authorization Bearer YOUR_API_KEY 接口鉴权。
Accept application/json 建议固定为 JSON 响应。
Content-Type application/json 或 multipart/form-data 文生图使用 JSON；图生图支持 JSON 图片 URL 或表单上传图片。

文生图接口

POST https://images.97api.com/v1/images/generations application/json

请求示例

{
  "model": "gpt-image-2",
  "prompt": "A black-and-white fashion editorial photo of a male model with a lean, defined torso, sitting on a tall stool while leaning back with his legs extended forward. He wears an oversized black suit with the blazer open, revealing his abs, paired with wide-leg trousers and white sneakers. Dramatic studio lighting creates strong shadows and a minimalist, high-contrast atmosphere. The pose appears weightless and artistic, conveying a modern, avant-garde aesthetic.",
  "aspect_ratio": "1:1",
  "size": "1254x1254",
  "quality": "high",
  "output_format": "webp",
  "n": 1,
  "response_format": "url"
}

图生图接口

POST https://images.97api.com/v1/images/edits JSON 或 Multipart

JSON 图片 URL 请求

当输入图片已在公网可访问时，可使用 images 数组传入图片 URL。

{
  "model": "gpt-image-2",
  "prompt": "把男性换成女性",
  "aspect_ratio": "1:1",
  "size": "1254x1254",
  "quality": "high",
  "output_format": "webp",
  "n": 2,
  "response_format": "url",
  "images": [
    {
      "image_url": "https://webimg.97api.com/images/2026/06/21/1782026038_000603e525f0cbf64e0cfdbb0f1a9026.png"
    }
  ]
}

Multipart 表单上传请求

当需要直接上传本地图片时，使用 multipart/form-data。字段名可参考下表。

字段 示例值 说明
model gpt-image-2 图片模型。
prompt 把男性换成女性 编辑指令。
aspect_ratio 1:1 必须与 size 匹配。
size 1254x1254 输出尺寸。
quality high 图片质量。
response_format url 返回图片 URL。
image image.webp 上传的输入图片文件。
n 2 生成数量。

curl 示例

curl -X POST "https://images.97api.com/v1/images/edits" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Accept: application/json" \
  -F "model=gpt-image-2" \
  -F "prompt=把男性换成女性" \
  -F "aspect_ratio=1:1" \
  -F "size=1254x1254" \
  -F "quality=high" \
  -F "response_format=url" \
  -F "n=2" \
  -F "image=@./image.webp"

参数说明

参数 类型 必填 说明
model string 是 当前使用 gpt-image-2。
prompt string 是 文生图提示词或图生图编辑指令。
aspect_ratio string 是 画幅比例，只支持本文档列出的枚举值。
size string 是 输出尺寸，必须与 aspect_ratio 对应。
quality string 否 图片质量，常用值为 high。
output_format string 否 输出图片格式，例如 webp。
n number 否 生成数量。
response_format string 否 使用 url 时返回图片链接。
images array 图生图 JSON 请求必填 图片 URL 数组，格式为 {"image_url": "https://..."}。
image file 图生图 Multipart 请求必填 上传的输入图片文件。

廉价渠道尺寸规则

重要：aspect_ratio 和 size 只支持下表组合。提示词中不要再写类似“生成 1024x1024 图片”“16:9 构图”等尺寸限制，否则容易与接口参数冲突。

aspect_ratio size
1:1 1254x1254
16:9 1666x944
9:16 944x1665
2:3 1024x1536
3:2 1536x1024

调用建议

同步超时

生图可能超过 60 秒，调用方、反向代理和网关的超时时间建议统一设置到 120-300 秒（廉价渠道只支持120s）。

图片 URL

图生图 JSON 请求中的 image_url 需要可公网访问，且服务端能正常下载。

数量 n

多图生成会增加耗时。业务上如无必要，建议先使用 n=1。

密钥安全

不要把真实 API Key 写入前端页面或公开仓库，建议通过服务端转发请求。
